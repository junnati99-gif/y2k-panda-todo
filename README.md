# 🐼 PandaDo — Gen Z Y2K Sassy To-Do App

> *"Bestie wake up, no cap that task is due fr fr 💀"*

**PandaDo** is a retro Y2K cyber-pop themed Android productivity app. It features **Bao**, a sassy Duolingo-style panda mascot who gives motivational vibe checks, tracks daily streaks, and celebrates completed quests with confetti!

## ✨ Features
- 🐼 **Bao the Sassy Mascot**: Streak tracker (`🔥 5 Day Streak`) & sassy quote generator.
- 🌟 **Star & Confetti Celebrations**: 60-particle confetti burst on task completion with **+50 Panda Stars**.
- 👯‍♀️ **Collaborative Squad Boards**: *Main Quests ⭐*, *Besties Collab 👯‍♀️*, *Y2K Side Quests 💿*, and *Dorm Era 🍕*.
- ⏰ **Sassy Push Reminders**: Custom reminder schedules with Gen Z slang push alerts.
- 📱 **Interactive Widgets**: Slang of the Day flashcards & Daily Vibe meter.
- 💾 **Offline-first**: Powered by Android Room Database.

## 🛠️ Built With
- Kotlin & Jetpack Compose (Material 3)
- Room Database & Coroutines
- Y2K Neo-Brutalism Cyber-Pop Design
